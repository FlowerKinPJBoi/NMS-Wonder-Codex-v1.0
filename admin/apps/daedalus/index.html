    Beginner guide

    What should I upload?

    1. Reference screenshots: images showing what the finished build looks like.
    2. Known build file: an exported .nmsship, .nmsprefab, .NMSBASE, or objects JSON—not your complete save.
    3. Prefab references: if an .NMSBASE places a named prefab, add the matching .nmsprefab definition when prompted.
    4. Analyze: Daedalus reads the records locally and explains the construction.
    5. Export: save a blueprint report or a self-contained Blender Bridge job.
    v0.9.1 keeps image studies, prefab definitions, generated sign attempts, inspection models, learning records, and source packages outside the game-save write path.

    The image-only path creates guide geometry with export disabled. Learning packages remain local until you export them, and the ground-truth path retains the source-hash, package-entry, and protected-anchor checks.
