# Content prepared for the next edition

These are design inputs, not enabled v0.1.1 game systems.

- **finding-nemo-schedule.json**: 256 worksheet records. Biomes 41–256 extend
  the nine-theme sequence established from galaxy 7 onward in the supplied
  Finding Nemo schedule. Earlier historical entries remain unchanged. Galaxy
  1 has no source biome. The worksheet's galaxy names stop at 130, so later
  source names are null.
- **galaxies.json**: the complete canonical 1–256 name roster, with sources,
  cross-checks, and the distinction between normal NMS travel and the FFC
  game's requested 256-step loop. Join by galaxy number, not a display name.

The source workbook abbreviates #2 Hilbert and #4 Hesperius; the canonical
roster uses Hilbert Dimension and Hesperius Dimension. Its #21 Loychazing
and #93 Boealalosni differ in their last character from Loychazinq and
Boealalosnj. The workbook's existing names were preserved; the game roster
uses the verified full names.

The weekly FFC themes are not NMS galaxy classifications. No automatic
calendar dates have been inferred. See ../docs/NEXT-EDITION.md for the
proposed weekly challenge, galaxy warp, and community-project rules.
