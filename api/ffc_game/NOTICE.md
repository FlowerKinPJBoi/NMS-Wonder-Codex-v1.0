# FFC Wilds

This is an independent fan community game built for Fishing, Farming & Crafting.
No Man's Sky names and the underlying game belong to their respective owners.
This project is not an official Hello Games product.

The Python implementation and included vector/PNG artwork were created for this
FFC project. No Cat Bot source code, Cat Bot artwork, or extracted NMS artwork is
included. Cat Bot inspired the appearance-and-collection game concept.

The Discord client library is an external dependency installed by Setup; its
own license applies. Third-party libraries are not bundled in the source ZIP.

Item names and source references are documented in docs/CATALOG-SOURCES.md.
Recipe quantities, event odds, timers, XP, companion card grades and node effects
are FFC game rules. Rewards remain in the Discord collection database.
