WONDER CODEX EDITOR 1.0.0 - THIRD-PARTY CREDITS

NO MAN'S SKY SAVE EDITOR BY GOATFUNGUS
https://github.com/goatfungus/nmssaveeditor
Wonder Codex Editor builds on GoatFungus's save editor and retains its original
menus and data operations. The installer downloads the original 1.21.0 engine
from a fixed repository revision and verifies its exact SHA-256 checksum.
The author's original engine binary is not changed.

CosmosBridge.jar supplies the Wonder Codex COSMOS compatibility overlay. It
contains Wonder Codex additions and modified native editor classes and works
with the original engine. Original engine attribution remains applicable.
The Wonder Codex desktop extension source is included in source/.

TAZmd NMS CORVETTE OPTIMIZER

result validation and update notices; it does not supply the optimization
algorithm or claim ownership of TAZmd's software.
